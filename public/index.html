Playstation Demo Disc API

About

This is a simple API meant to get comfortable with creating APIs in general. THIS IS NOT A COMPLETE LIST - these are largely demo discs that I care about personally. See Acknowledgements below for the source.

Use - available endpoints

  • GET /api/discs - return all discs.
  • GET /api/disc/SCUS-##### - return data for a specific disc with this ID
  • POST /api/discs/ - add new demo_disc (include: id, title, release_date, description)
