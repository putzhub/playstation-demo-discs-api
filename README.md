# Playstation Demo Disc API
This hosts a server running an API that retrieves data about some Playstation Demo Discs.

**Link to project:** https://playstation-demo-discs-api.onrender.com/

## How It's Made:

**Tech used:** HTML, CSS, JavaScript, Node, Express

This project is built using Node.js and Express as an exercise in creating my own API. The main focus is to get more comfortable building an API that responds to requests properly.

## Optimizations

Since this is mainly a learning exercise I kept it intentionally simple, but it would be fun to go further with this project. You could add an entry to include which games are actually included on any given disc, for example. Obviously it would make sense to use a database of some sort as well that people could contribute to. It would be nice to have the ability to work with the API itself on the server page as well.

## Lessons Learned:

The main things I learned from this project are: 

* How to setup a web service on render's platform
* How to send requests using: postman, REST client in visual studio code and curl
* How to create node projects and use frameworks like express
